# M16 — Fallback, Clarification, And Feedback Loop

- Preserved grounded no-evidence behavior and added a backend clarification contract for missing sources, ambiguous wording, dates, and exact-quote cases.
- Automatically records missing-evidence feedback when retrieval returns no usable context.
- User chat can submit missing-source hints tied to the failed question/request.
- Helpful and not-helpful answer feedback is persisted instead of staying client-only.
- Admin Actions console exposes top failed query patterns and recent feedback for closed-loop source/indexing review.
