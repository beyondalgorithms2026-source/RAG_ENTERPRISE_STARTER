# M11 — Admin Workspace Polish And Operational UX

- Added reusable saved views and filter controls across the admin sources, jobs, traces, and audit pages so operators can reopen meaningful operational slices without rebuilding filters from scratch.
- Upgraded the sources page with bulk operator actions on top of the existing live control plane: multi-select source updates, bulk corpus/sensitivity changes, bulk reindex, and bulk enrich.
- Improved jobs and traces ergonomics with filtered summary cards, better sort options, and detail selection that stays aligned with the currently visible operational view.
- Expanded eval usability with a side-by-side comparison surface for the available report slots so operators can compare report coverage, pass rate, evaluated modes, and profile snapshots without leaving the console.
- Added an explicit approval-inbox summary/stub to the admin overview so non-developer operators can see where a future approval workflow will live without implying that M15 functionality already exists.
